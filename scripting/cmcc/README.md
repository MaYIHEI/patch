# 🩹 cmcc · 中国移动话费流量

桌面显示中国移动话费、流量和账号信息，登录凭证自动续期，不用反复手动更新。

21 种样式，按尺寸挑：

| 分组 | 样式 |
|---|---|
| 全景 | 一个组件看全：余额、本月、每项剩余和预测、积分网龄、近 7 天；多个号点顶部标签切换 |
| 一眼看懂 | 自适应（默认）、大字余额、状态色块、账单卡 |
| 够不够用 | 今日额度、倒计时、用量预测、环比、性价比、用量月报 |
| 换个说法 | 地铁线路、网龄徽章、终端、话费小票 |
| 多个号 | 多号翻页、控制台、双号对照、谁先用完、账本记录 |
| 锁屏 | 圆形 / 长条 / 单行、今日额度圆形、倒计时圆形 |

浅色白底、深色深灰底，跟随系统切换；也可在「外观」里换纯色或相册图片背景。点小组件右上角的时间可以立即刷新。今日额度、环比、用量月报要本机记几天历史才准。

## 📲 一键安装

iPhone 上点击下方链接, Scripting 会自动导入:

```
scripting://import_scripts?urls=%5B%22https%3A%2F%2Fwww.imarkr.com%2Fapi%2Fgithub%2Fdownload%2FMaYIHEI%2Fpatch%2Fscripting%2Fcmcc.zip%22%5D
```

## 🚀 使用步骤

1. 装好 [Scripting](https://apps.apple.com/app/scripting/id6479691128) 和 Loon，Loon 里装好 BoxJS
2. Loon 导入 [paperclip 中国移动插件](https://github.com/MaYIHEI/paperclip/tree/main/app/cmcc)（Loon → 插件 → 添加，地址 `https://raw.githubusercontent.com/MaYIHEI/paperclip/refs/heads/main/loon/cmcc/cmcc.lpx`），先在后台划掉「中国移动」App 再重新打开，收到「获取成功」通知（直接切回已打开的 App 不会触发）
3. 保持 Loon 开启，在 Scripting 里运行 `cmcc`，点「从 BoxJS 导入」，看到 ✅ 即完成
4. iPhone 桌面长按空白 → + → 搜 Scripting → 选 `cmcc`

导入一次后小组件每次刷新会自动续期，之后不再需要 Loon。提示「凭证失效」时重复第 2、3 步。设置页「检查更新」可一键升级到最新版本。

**多账号**：在中国移动 App 里用「切换账号」登录另一个号（不要「退出登录」），划掉重开 App 后再点「从 BoxJS 导入」，两个号都会保存。桌面放两个小组件，分别长按 → 编辑小组件 → 参数，填各自手机尾号 4 位；不填显示第一个号。

**小组件参数**：写「样式名 尾号」，如 `账单卡 1234`、`双号对照 主号:1234,副号:5678`（中英文逗号、冒号都行）。只写尾号用这个尺寸的默认样式；只写两个尾号用双号对照；什么都不写用默认样式和第一个号。在 cmcc 的「小组件 → 换个样式」里点「用这个样式」会设为默认并复制参数。

## ⚙️ 配置项

| 项 | 默认 | 说明 |
|---|---|---|
| BoxJS 域名 | `boxjs.com` | 「设置」里改，和你 BoxJS 的访问域名一致 |
| 刷新间隔 | 2 小时 | 「设置」里改，1 / 2 / 4 小时 |

凭证只存在本机 Keychain，查询结果缓存 5 分钟；本机历史只存余额和剩余量，保留 62 天。
