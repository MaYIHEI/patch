# 🩹 checkin · 签到总览

桌面显示各签到脚本今天的结果、奖励和资产。数据来自 Loon 里的签到脚本（汇总地址或 BoxJS），小组件只负责读取和显示，不含任何签到代码。

- 25 种样式，每种只出现在放得下的尺寸里：小号 13 种、中号 23 种、大号 19 种，锁屏圆形 2 种、长条 2 种
- 两种外观：「素净」跟随系统深浅色；「自定义」可选纯色或相册图片（可调模糊、暗化），文字颜色自动黑白，强调色可选
- 使用真实 App 图标，失败的可以一键补签，需重抓的点「打开 App」直接跳过去
- 本机记录历史（默认 90 天），日历、收益、热力图、成就等样式会越用越丰富
- 锁屏实时活动、控制中心按钮

## 📲 一键安装

iPhone 上点击下方链接，Scripting 会自动导入：

```
https://www.scripting.fun/import_scripts/?urls=%5B%22https%3A%2F%2Fwww.imarkr.com%2Fapi%2Fgithub%2Fdownload%2FMaYIHEI%2Fpatch%2Fscripting%2Fcheckin.zip%22%5D
```

---

## 🚀 使用步骤

1. 装好 [Scripting](https://apps.apple.com/app/scripting/id6479691128) 和 Loon
2. 在 Scripting 里运行 `checkin`。读不到数据时首页会显示三步引导：
   - 一键导入「Paperclip · 签到合集」插件
   - 去 Loon 跑一次签到（Cookie 用「Paperclip · Cookie 抓取合集」插件获取）
   - 回来点刷新
3. 首页「样式库」里挑样式，点「用这个样式」会设为该尺寸的默认样式，并复制参数
4. iPhone 桌面长按空白 → + → 搜 Scripting → 选 `checkin`。不填参数就用默认样式；想同时放几个不同样式，长按小组件 → 编辑小组件 → 参数里粘贴样式名，如 `中·资产钱包`（只写 `钱包` 也行）

样式和当前尺寸对不上时，自动换成这个尺寸的默认样式。

## 🏠 App 首页

| 入口 | 作用 |
|---|---|
| 样式库 | 按小、中、大、锁屏分类，精选 + 更多样式，真实比例预览 |
| 外观 | 素净 / 自定义，顶部实时预览 |
| 显示哪些 | 勾选、拖动排序要显示的脚本；有问题时是否排在前面；所有小组件共用 |
| 设置 | 数据来源、刷新间隔、实时活动、控制中心按钮、历史记录、检查更新 |

「需要处理」列出需重抓和失败的脚本：需重抓的点「打开 App」，失败的点「补签」（脚本支持时会现跑一次），也可以「全部失败项一键补签」。超过 7 天没有新结果的脚本收进「长期未运行」，不算需要处理。

小组件里点某个脚本那一行，会打开它的详情：最近 7 天的结果、失败原因、补签或打开 App。

## ⚙️ 设置项

| 项 | 默认 | 说明 |
|---|---|---|
| 数据来源 | 自动 | 自动：先读 Loon 汇总地址，失败再读 BoxJS；也可以固定只用其中一个 |
| BoxJS 地址 | `https://boxjs.com` | 数据来源选 BoxJS 时可改 |
| 刷新间隔 | 30 分钟 | 15 / 30 / 60 分钟，实际由系统决定 |
| 历史保留 | 90 天 | 30 / 90 / 180 / 365 天 |

**实时活动**：设置里点「开始早间签到实时活动」，锁屏和灵动岛显示今日进度。系统不允许没人操作时自动弹出，需要手动开启。

**控制中心按钮**：控制中心 → 左上角 + → 添加控制 → Scripting → `checkin`。点一下会读数据、刷新小组件，并开启或刷新实时活动。

## 🔌 给脚本作者：签到状态协议 v1

脚本跑完后把结果写进代理工具的持久化存储，小组件就能显示：

- 登记索引 `checkin_registry`：`{ "<状态key>": { "name": "京东", "author": "作者", "url": "可选", "run": "补签地址（可选）", "open": "打开 App 的链接（可选）" } }`
- 每个状态 key 的值：`{ "v": 1, "s": "ok" | "cookie" | "fail" | "none", "t": 毫秒时间戳, "msg": "今日奖励", "asset": "资产（可选）", "exp": 凭证过期毫秒时间戳（可选） }`

`s` 为 `none` 的不显示；旧记录只有 `s`、`t`、`msg` 也能显示。完整说明见 [paperclip 签到协议](https://github.com/MaYIHEI/paperclip/blob/testing/docs/checkin-protocol.md)。
