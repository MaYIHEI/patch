# 🩹 checkin · 签到总览

桌面显示各签到脚本今天的结果和资产。数据来自 BoxJS，小组件只负责读取和显示，不含任何签到代码。

27 种样式，小、中、大三种尺寸都能用，另有锁屏圆形和长条：

| 样式 | 说明 |
|---|---|
| A 列表 | 状态点 + 名称 + 奖励 + 资产，顶部计数和分段进度条 |
| B 环形 | 完成度圆环，中、大号带资产小卡 |
| C 打卡日历 | 当月格子，颜色深浅是当天成功率，标题是连签天数 |
| D 图标墙 | App 图标网格，有问题的描边；小号只放有问题的 |
| E 资产钱包 | 只显示资产卡片 |
| F 终端日志 | 等宽字 `✓ ✗ !` 逐行结果 |
| G 时间线 | 按签到时间分组 |
| H 收益统计 | 本月累计奖励 + 最近 7 / 30 天柱状图 |
| I 锁屏 | 圆形完成度、长条「签到 28/31 · 需处理项」 |
| J 热力图 | 每个脚本一行、每天一格，看哪个老出问题 |
| K 每日任务 | 等级经验 + 今日任务 |
| L 签到小票 | 虚线票据，逐行奖励和合计 |
| M 大字状态 | 有问题整张变红显示数量，全部正常变绿 |
| N 兑换目标 | 资产离目标还差多少、按近 7 天估算还要几天 |
| O 分类看板 | 商场、影音、社区、工具、生活各自完成数 |
| P 聚光灯 | 每次刷新轮换一个脚本的大卡片 |
| Q 交互翻页 | 小组件上点 ‹ › 翻页、⟳ 刷新 |
| R 成就徽章 | 连签、零失败周、累计千分、全勤月等 |
| S 签到天气 | 全部成功晴，有失败下雨，需重抓 ≥ 3 雷暴 |
| U 地铁线路 | 今天的签到按时间排成站，出问题的是故障站 |
| V 体检评分 | 100 分起扣，三项子分，和昨天比 |
| W 环比对比 | 今天比昨天、本周比上周 |
| X 过期倒计时 | 凭证还有几天过期（需要脚本提供过期时间） |
| Y 作者生态墙 | 按脚本作者分组 |
| Z 积分气泡 | 资产越多气泡越大 |
| AA 实时活动 | 锁屏和灵动岛显示今日进度 |
| AB 控制中心按钮 | 控制中心一键刷新并开启实时活动 |

两套皮肤：「素净」跟随系统深浅色，「彩色」深色底、品牌色资产卡。绿色表示成功，红色表示需要重抓 Cookie，橙色表示失败；结果不是今天的会标出日期。

## 📲 一键安装

iPhone 上点击下方链接，Scripting 会自动导入：

```
https://www.scripting.fun/import_scripts/?urls=%5B%22https%3A%2F%2Fwww.imarkr.com%2Fapi%2Fgithub%2Fdownload%2FMaYIHEI%2Fpatch%2Fscripting%2Fcheckin.zip%22%5D
```

## 🚀 使用步骤

1. 装好 [Scripting](https://apps.apple.com/app/scripting/id6479691128)，代理工具（Loon / Surge / Quantumult X）里装好 BoxJS 和支持「签到状态」的签到脚本
2. 让签到脚本至少跑一次，结果会写进 BoxJS
3. 在 Scripting 里运行 `checkin` → 更多设置，关掉「演示数据」，确认 BoxJS 地址后点「保存地址并刷新」；「新手引导」里点「开始检查」可以逐项确认
4. iPhone 桌面长按空白 → + → 搜 Scripting → 选 `checkin`

**预设**：在 `checkin` 首页的「我的预设」里新建或编辑，选样式、皮肤、背景、显示哪些脚本（可拖动排序）、有问题时是否优先显示，顶部可以实时预览。点「复制参数」后，长按桌面小组件 → 编辑小组件 → 参数里粘贴预设名。参数不填或找不到时用「A 列表 · 素净」。改了预设，用它的小组件会跟着变。

**处理按钮**：需重抓的「打开 App」会打开 `checkin` 页面并提示怎么重抓。失败的「补签」在脚本登记了补签地址时可以直接点，小组件里会在后台现跑一次该脚本，时间不够时显示「补签中，稍后刷新」；没有登记的显示「不支持补签」。`checkin` 首页还有「全部失败项一键补签」，会逐个补签并显示进度。

**历史记录**：日历、收益、热力图等样式用的是本机历史。小组件和 App 每次读到数据，会按北京时间存一份当天结果，默认保留 90 天（更多设置里可改）。刚开始用时这些样式会提示「已记录 N 天」，签几天就有内容了。

**实时活动和控制中心**：在 `checkin` 首页点「开始早间签到实时活动」，锁屏和灵动岛会显示今日进度。控制中心 → 添加控制 → Scripting → `checkin`，之后点一下就会刷新数据并开启或更新实时活动。

读取 BoxJS 需要代理工具保持开启；连不上时小组件显示上一次读到的结果，时间前带 ⚠。

## ⚙️ 配置项

| 项 | 默认 | 说明 |
|---|---|---|
| 演示数据 | 开 | 开着时显示示例数据，不读 BoxJS |
| BoxJS 地址 | `https://boxjs.com` | 和你 BoxJS 的访问地址一致 |
| 历史保留天数 | 90 天 | 30 / 90 / 180 / 365 天 |

## 🔌 给脚本作者：签到状态协议 v1

脚本跑完后把结果写进代理工具的持久化存储，小组件就能显示：

- 登记索引 `checkin_registry`：`{ "<状态key>": { "name": "京东", "author": "作者", "url": "可选", "run": "补签 URL（可选）" } }`
- 每个状态 key 的值：`{ "v": 1, "s": "ok" | "cookie" | "fail" | "none", "t": 毫秒时间戳, "msg": "今日奖励", "asset": "资产（可选）", "exp": 凭证过期毫秒时间戳（可选） }`

`s` 为 `none` 的不显示。旧记录只有 `s`、`t`、`msg` 也能显示。没写进 `checkin_registry` 的 paperclip 脚本按自带列表读取。
