# 🩹 loon-panel · Loon 面板

在桌面看机场流量还剩多少、每天用了多少、哪天会用完，同时看各策略组正在用的节点、延迟和出口，还能直接在小组件上切换模式和节点。

> 需要 Loon 3.5.1 (983) 及以上，配合本目录里的「Loon 面板」插件使用。

- 多个机场订阅，每个起个名字；近 14 / 30 天每日用量柱状图，按近 7 天日均推算哪天用完，或是否够用到到期日
- 节点体检：插件定时测各策略组当前节点（可加测指定策略组的全部节点）的延迟、出口 IP、国家、ASN 和运营商
- 大号看板上点模式按钮切换全局直连 / 分流 / 全局代理，点策略组那一行切到体检最快的节点
- 两种外观：「素净」跟随系统深浅色；「自定义」可选纯色或相册图片，文字颜色、强调色可调

## 🚀 使用步骤

1. 装好 [Scripting](https://apps.apple.com/app/scripting/id6479691128) 和 Loon，点上面的链接导入 `loon-panel`
2. 在 Scripting 里运行 `loon-panel`，首页「开始使用」三步：
   - **导入 Loon 插件**：一键添加「Loon 面板」插件，回来点刷新
   - **添加机场订阅**：填名字和订阅链接，可以加多个；第一个是主订阅
   - **跑一次体检**：测当前节点的延迟和出口，之后插件按设定频率自动体检
3. 首页「样式库」里挑样式，点「用这个样式」会设为该尺寸的默认样式，并复制参数
4. iPhone 桌面长按空白 → + → 搜 Scripting → 选 `loon-panel`。不填参数就用默认样式；想同时放几个不同样式，长按小组件 → 编辑小组件 → 参数里粘贴样式名，如 `中·节点体检`（只写 `体检` 也行）

**读不到数据？** 保持 Loon 开启，用 Safari 打开 `http://1.1.1.1/loon-panel/data`，能看到一段 JSON 才说明 Loon 已经接管；看不到就检查「Loon 面板」插件是否已启用。不要把 `1.1.1.1` 加进 Loon 的 `bypass-tun` 或 `skip-proxy`，否则请求不会经过 Loon。

## 🧩 样式

| 尺寸 | 样式 | 内容 |
|---|---|---|
| 小 | 用量环 | 主订阅已用比例、剩余流量、预计用完日期 |
| 小 | 当前节点 | 主策略组正在用的节点、延迟、出口 IP 和运营商 |
| 中 | 用量趋势 | 主订阅用量和预测，近 14 天每日用量 |
| 中 | 节点体检 | 体检过的节点延迟和运营商，正在用的排前面 |
| 大 | 全景看板 | 模式切换、多机场对比、策略组当前节点和延迟（点一下切到最快）、出口信息 |
| 锁屏 | 锁屏 | 圆形：主订阅已用；长条：剩余流量、预测、当前节点延迟 |

样式和当前尺寸对不上时，自动换成这个尺寸的默认样式。

## ⚙️ 配置项

小组件（App → 设置）：

| 项 | 默认 | 说明 |
|---|---|---|
| 刷新间隔 | 30 分钟 | 15 / 30 / 60 分钟，实际由系统决定；订阅用量 30 分钟内复用上次结果 |
| 主策略组 | 兜底策略 | 小号「当前节点」、锁屏长条、看板出口信息用它 |
| 看板策略组 | 前 4 个 | 大号看板显示哪些策略组，按勾选顺序 |

Loon 插件参数：

| 项 | 默认 | 说明 |
|---|---|---|
| 体检频率 | `*/30 * * * *` | Cron 表达式 |
| 全量体检的策略组 | 空 | 默认只测各策略组当前选中的节点；填在这里的策略组测全部节点，多个用英文逗号分隔 |
| 单次超时 | 3000 毫秒 | 超过判为不可用 |
| 测速地址 | `http://www.gstatic.com/generate_204` | |
| 出口 IP 地址 | `https://api.ipify.org` | 返回出口 IP 的地址，纯文本或带 `ip` 字段的 JSON |

**订阅链接**只保存在本机钥匙串里，不写进文件；用量历史只存数字，保存在本机约 60 天。任何会返回 `Subscription-Userinfo` 头的地址都能用；需要额外请求头（比如自建面板的 `Authorization`）时，在链接末尾加 `#headers=` 和 URL 编码后的 JSON，例如 `#headers=%7B%22Authorization%22%3A%22Bearer%20xxx%22%7D`。

## 🔧 接口说明

| 地址 | 作用 |
|---|---|
| `http://1.1.1.1/loon-panel/data` | 运行模式、策略组、当前节点、体检结果（Loon 插件直接返回，不出网） |
| `http://1.1.1.1/loon-panel/set?mode=0\|1\|2` | 切换全局直连 / 分流 / 全局代理，复测当前节点后返回最新状态 |
| `http://1.1.1.1/loon-panel/set?group=<策略组>&node=<节点>` | 切换策略组，复测新节点后返回最新状态 |
| `http://1.1.1.1/loon-panel/set` | 不带参数：复测各策略组当前节点 |
| 订阅链接 | 小组件直接 GET，读响应头 `Subscription-Userinfo`（upload / download / total / expire） |

## ⚠️ 已知限制

- Loon 脚本拿不到实时网速、流量统计和连接列表，所以面板不显示这些
- 体检结果来自插件的定时任务，不是实时测速；插件每次最多跑约 100 秒，节点很多时剩下的下次再测
- 日用量按两次读取相减得到，小组件一整天都没刷新过的日子，会和后一天平分用量
