# 🩹 loon-panel · Loon 面板

在桌面看机场流量还剩多少、今天用了多少、哪天会用完，看节点的延迟、稳定性、解锁和出口质量，还能直接在小组件和控制中心切换模式和节点。

> 需要 Loon 3.5.1 (983) 及以上，配合本目录里的「Loon 面板」插件使用。部分检测需要 Build 988 以上。

- **机场流量**：多机场；今天合计、近 1 小时速度、每小时和近 30 天用量；预计用完日期、每天可用额度、每月重置日、性价比、用量提醒
- **节点**：定时体检延迟和出口，保留最近 24 次看折线和可用率；流媒体与 AI 解锁；网络切换后自动复测；当前节点挂了发通知或自动切换；锁定策略组，被还原就改回来
- **深度检测**：IP 类型和多来源风险、三网延迟和入站路径、近似回程、IP 黑名单、DNS 泄漏、NAT 类型、带宽测速
- **控制**：小组件上切模式、切最快、体检、更新订阅；控制中心按钮；体检完自动刷新小组件
- **36 种样式**：小号 12、中号 13、大号 5、锁屏 6；素净或自定义外观

## 🚀 使用步骤

1. 装好 [Scripting](https://apps.apple.com/app/scripting/id6479691128) 和 Loon，点上面的链接导入 `loon-panel`
2. 在 Scripting 里运行「Loon 面板」，「小组件」页顶部列出还没做的步骤：
   - **导入 Loon 插件**：一键添加「Loon 面板」插件，回来点刷新
   - **添加机场订阅**：选 Loon 配置文件一次导入，或从剪贴板、手动添加；第一个是主订阅
   - **跑一次体检**：测当前节点的延迟和出口，之后插件按设定频率自动体检
3. 「小组件」页 → 样式，挑好后点「用这个样式」，会设为该尺寸的默认样式，并复制参数
4. iPhone 桌面长按空白 → + → 搜 Scripting → 选「Loon 面板」。不填参数就用默认样式；想同时放几个不同样式，长按小组件 → 编辑小组件 → 参数里粘贴样式名，如 `中·节点体检`（只写 `体检` 也行）

**读不到数据？** 保持 Loon 开启，用 Safari 打开 `http://1.1.1.1/loon-panel/data`，能看到一段 JSON 才说明 Loon 已经接管；看不到就检查「Loon 面板」插件是否已启用。不要把 `1.1.1.1` 加进 Loon 的 `bypass-tun` 或 `skip-proxy`，否则请求不会经过 Loon。

## 🧩 样式

| 尺寸 | 样式 |
|---|---|
| 小 | 总览、用量环、当前节点、今日流量、每日额度、多机场、倒计时、解锁、模式开关、IP 质量、网络安全、环比 |
| 中 | 总览、用量趋势、节点体检、多机场、解锁、今日时段、延迟排行、控制台、策略组卡片、切换器、事件时间线、三网延迟、性价比 |
| 大 | 全景看板、用量月报、节点全景、线路体检报告、切换器 |
| 锁屏 | 圆形：锁屏（已用）、延迟、今日；长条：锁屏、三网；单行：锁屏 |

样式和当前尺寸对不上时，自动换成这个尺寸的默认样式。总览和全景看板按有没有机场变化；其他流量样式需要机场，样式库里有标注。

IP 质量、三网延迟、网络安全、线路体检报告显示的是深度检测的结果，要先在 App 里跑一次。

## 🏠 App 页面

底栏四页：

| 页面 | 作用 |
|---|---|
| 小组件 | 还没做的设置步骤；按尺寸预览当前样式；样式库（真实比例预览，可切换示例数据）；外观（素净 / 自定义） |
| 机场 | 从 Loon 配置文件导入、从剪贴板或手动添加，改名、更换链接、删除、「调整顺序」里拖动排序；点进去看每小时和近 30 天用量，填每月重置日和每期价格 |
| 节点 | 主策略组的延迟和可用率、选择主策略组、运行模式、常用策略组、全部策略组、立即体检、更新订阅、事件记录 |
| 设置 | Loon 连接测试、节点检测、用量提醒、刷新间隔、自动刷新、数据和缓存、检查更新 |

点策略组进去：可以设为常用或主策略组、让解锁样式看这个组、打开全量体检、锁定当前选择；节点按延迟排序，点一下切换；底部有当前节点的解锁结果和「深度检测」。「全部策略组」里可以拖动常用的顺序。「立即体检」马上复测各策略组正在用的节点，「更新订阅」会跳到 Loon。

控制中心：左上角 + → 添加控制 → Scripting → Loon 面板。按钮切到最快，开关切分流和全局。

## ⚙️ 配置项

App → 设置：

| 项 | 默认 | 说明 |
|---|---|---|
| 刷新间隔 | 30 分钟 | 15 / 30 / 60 分钟，实际由系统决定；这只是小组件重绘的频率，订阅按各自的读取方式读 |
| 订阅读取方式 | 12 小时一次 | 每个机场单独选 1 / 3 / 6 / 12 / 24 小时，或手动填写；手动填写不定时请求订阅。一次读取只发一个请求，手动刷新 30 分钟内不重复请求 |
| 打开官网并同步 | - | 给要先打开官网才能拉订阅的机场用：在网页窗口登录，关掉窗口后读一次订阅，读不到就从页面文字找用量并让你确认 |
| 用量提醒 | 80% 和 90%、3 天内用完 | 另有到期前 3 天，默认关 |
| 网络切换后复测 | 开 | Wi-Fi 和蜂窝切换时体检当前节点 |
| 节点异常发通知 | 关 | 当前节点连续 3 次超时时发通知；Loon 自己也会提示节点问题。DIRECT 不算节点；自动切换和改回锁定总会通知 |
| 挂了自动切到最快 | 关 | 切到同一策略组里体检过且能用的最快节点；锁定的策略组不会切 |
| 单次超时 | 5 秒 | 超过判为不可用 |
| 测速地址 | `http://www.gstatic.com/generate_204` | |
| 出口 IP 地址 | `https://api.ipify.org` | 返回出口 IP 的地址，纯文本或带 `ip` 字段的 JSON；查不到时改用 `ip-api.com` |

在策略组页面里设置：

| 项 | 默认 | 说明 |
|---|---|---|
| 常用 | 前 4 个 | 想在小组件上切换的策略组，数量不限。切换器、策略组卡片、全景看板只翻这些，点 `1/3 ›` 翻页；没设时翻全部 |
| 主策略组 | 兜底策略 | 小号「当前节点」、锁屏长条、看板出口信息用它 |
| 解锁样式看这个组 | 主策略组 | 解锁样式看哪个策略组当前节点的结果 |
| 全量体检 | 关 | 每次体检测这个组的全部节点；默认只测当前节点 |

Loon 插件参数只有一项：

| 项 | 默认 | 说明 |
|---|---|---|
| 体检频率 | `*/30 * * * *` | Cron 表达式 |

**订阅链接**只保存在本机钥匙串里，不写进文件；用量历史只存数字，保存在本机约 60 天。深度检测和解锁检测会把节点的出口 IP 提交给第三方查询服务。任何会返回 `Subscription-Userinfo` 头的地址都能用；需要额外请求头（比如自建面板的 `Authorization`）时，在链接末尾加 `#headers=` 和 URL 编码后的 JSON，例如 `#headers=%7B%22Authorization%22%3A%22Bearer%20xxx%22%7D`。

## 🔧 接口说明

| 地址 | 作用 |
|---|---|
| `http://1.1.1.1/loon-panel/data` | 运行模式、策略组、当前节点、体检结果（Loon 插件直接返回，不出网） |
| `http://1.1.1.1/loon-panel/set?mode=0\|1\|2` | 切换全局直连 / 分流 / 全局代理，复测当前节点后返回最新状态 |
| `http://1.1.1.1/loon-panel/set?group=<策略组>&node=<节点>` | 切换策略组，复测新节点后返回最新状态 |
| `http://1.1.1.1/loon-panel/set?group=<策略组>&node=<节点>&lock=1` | 切换并锁定；`?group=<策略组>&lock=0` 解锁 |
| `http://1.1.1.1/loon-panel/set` | 不带参数：复测各策略组当前节点 |
| `http://1.1.1.1/loon-panel/deep?node=<节点>` | 深度检测，加 `&speed=1` 同时测速 |
| `POST http://1.1.1.1/loon-panel/opts` | 保存 App 里的设置，正文是要改的项（JSON），空字符串恢复默认 |
| 订阅链接 | 到了读取时间才发一个 GET（只取 1 字节），读响应头 `Subscription-Userinfo`（upload / download / total / expire） |

## ⚠️ 已知限制

- Loon 脚本拿不到实时网速、每个 App 的流量和连接列表。「近 1 小时速度」是订阅用量相减得到的，精度取决于机场多久更新一次用量，App 里会显示这个间隔
- 体检结果来自插件的定时任务，不是实时测速；插件每次最多跑约 100 秒，节点很多时剩下的下次再测
- 日用量按两次读取相减得到，小组件一整天都没刷新过的日子，会和后一天平分用量
- 解锁、三网、回程等结果只反映检测当时的情况；回程用的是同网络的外部探针，不是节点本机
- NAT 类型只能测手机当前分流规则下实际走的线路，不能指定节点
- 「Loon 运行中」只能判断手机上有 VPN 在跑，分不出是不是 Loon
- Loon 脚本读不到订阅链接，只能从配置文件或剪贴板导入；机场换了链接要重新导入。导入时先选读取方式，选之前不请求订阅；没有 `Subscription-Userinfo` 的订阅读不到用量，可以改成手动填写
