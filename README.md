# 🩹 patch

iOS 桌面小组件合集 · 把数据贴到主屏幕

> 一块块贴在桌面上,扫一眼就完事。

---

## 📂 目录

| 目录 | 平台 | 索引 |
|---|---|---|
| [`scripting/`](./scripting/) | [Scripting](https://scripting.fun) (TypeScript + SwiftUI) | [查看](./scripting/README.md) |
| [`scriptable/`](./scriptable/) | [Scriptable](https://scriptable.app) (JavaScript) | *(占位, 未来)* |

每个子目录的 README 里有该平台下所有小组件的清单、安装链接、使用说明。

---

## 🚀 通用安装方式

每个小组件都自带一个 `scripting://` 或 `scriptable://` 开头的一键安装链接,在 iPhone 上点击即可导入到对应 app。

具体每个小组件的安装链接与配置步骤,请进入对应子目录的 README 查看。
